## Posture Detection Research (2026-02-08)

### Research Sources
- Explore agent: YOLOv8-pose codebase analysis
- Librarian 1: Lightweight pose alternatives comparison
- Librarian 2: MoViNet for posture feasibility

### Key Findings

**YOLOv8n-pose / YOLO11n-pose:**
- 17 COCO keypoints (ears, shoulders, hips, knees — all needed for slouch)
- ~6MB model, 40+ FPS CPU, 60-80 FPS Apple Silicon
- Already using Ultralytics — zero new dependencies
- Can replace MediaPipe entirely for posture detection

**MoViNet for posture:**
- NOT suitable — clip-level classification vs frame-level needed
- No Kinetics classes for "slouching" / posture quality
- Wrong granularity (10-second windows vs per-frame angles)

**Other alternatives evaluated:**
- RTMPose-t: Fastest (120+ FPS CPU, 5MB) but requires MMPose framework
- MoveNet Lightning: Good (7MB, 50+ FPS) but TF ecosystem mismatch
- ViTPose: Too large for edge (90MB+)
- Lightweight OpenPose: Deprecated, not production-ready

### DECISION: Replace MediaPipe with YOLOv8n-pose
- Same keypoints needed (ears, shoulders, hips)
- Shares Ultralytics framework with existing phone detection
- Simpler stack: 2 models (YOLO detect + YOLO pose) vs 3 models (MediaPipe Pose + MediaPipe Face + YOLO)
- FPS improvement: eliminates duplicate frame processing
