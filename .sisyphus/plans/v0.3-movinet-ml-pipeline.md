# KID-WATCH v0.3 — ML-Based Detection Pipeline

## TL;DR

> **Quick Summary**: Replace the brittle threshold-based StudyDetector (MediaPipe Pose + FaceLandmarker heuristics) with a 3-model ML stack: YOLOv8n (phone), YOLOv8n-pose (posture), MoViNet-A2-Stream (studying/sleeping). Drop MediaPipe entirely.
> 
> **Deliverables**:
> - Trained MoViNet-A2-Stream model for studying/sleeping/other classification
> - YOLOv8n-pose integration for slouch detection (replaces MediaPipe Pose)
> - Redesigned EngagementEngine with new scoring formula (no gaze dependency)
> - Adapted CalibrationEngine for COCO 17-keypoint space
> - Full system integration: MediaPipe removed, single Python 3.11 runtime
> 
> **Estimated Effort**: Large (2-3 weeks)
> **Parallel Execution**: YES — 2 waves in Phase 0
> **Critical Path**: Phase 0 gates → Phase 1 → Phase 2 → Phase 3 → Phase 4 (training) → Phase 5 (pose) → Phase 6 (engine) → Phase 7 (integration)

## Context

### Original Request
Replace the fragile threshold-based StudyDetector with ML-based action recognition using MoViNet-A2 and modernize the detection stack.

### Interview Summary
**Key Discussions**:
- **Architecture**: 3-model stack (YOLO detect + YOLO pose + MoViNet) replaces 3-model stack (MediaPipe Pose + FaceLandmarker + YOLO)
- **Python Runtime**: Single Python 3.11 (NOT 3.12 — tensorflow-metal broken on 3.12)
- **MoViNet Classes**: 3 classes — studying, sleeping, other/neutral. Phone stays with YOLO.
- **Posture**: YOLOv8n-pose replaces MediaPipe Pose for slouch detection (17 COCO keypoints sufficient)
- **Gaze**: Intentionally dropped. No replacement. Engagement formula reweighted without it.
- **"Distracted"**: Temporal logic state (no confident prediction for N seconds), NOT raw model confidence
- **Data**: Kinetics-700 selective download + OUC-CGE. No in-domain eval set yet.
- **Testing**: Phase gate checks + agent QA scenarios. No unit test framework.
- **Rollout loop**: Deferred to future version.

### Research Findings
- **YOLOv8n-pose**: 17 COCO keypoints, ~6MB, 60-80 FPS on Apple Silicon, shares Ultralytics framework
- **MoViNet for posture**: NOT suitable — clip-level vs frame-level mismatch, no Kinetics slouching classes
- **Python 3.12 + TF 2.18 + tensorflow-metal**: BROKEN. Must use Python 3.11 + TF 2.17 + tensorflow-metal 1.2.0
- **Base→Stream conversion**: IMPOSSIBLE — architecturally different. Must fine-tune streaming checkpoint directly.

### Metis Review
**Critical Gaps Addressed**:
- Python version: Changed from 3.12 → 3.11 (tensorflow-metal compatibility)
- Phase 5 (streaming conversion): Removed — fine-tune streaming model directly
- Gaze signal: Dropped with explicit engagement formula redesign task
- CalibrationEngine: Added adaptation task for COCO keypoints
- MoViNet state management: Added reset_state() on camera disconnect
- Single-person assumption: Documented explicitly
- Kinetics download failures: Plan for 20-40% failure rate, target 1000 URLs/class

## Key Decisions

1. **Python 3.11 (NOT 3.12)**: tensorflow-metal 1.2.0 requires TF 2.17 which is stable on 3.11. TF 2.18 on 3.12 has confirmed Metal breakage.
2. **Fine-tune MoViNet-A2-Stream directly**: Base→Stream conversion is architecturally impossible (3D conv vs (2+1)D causal conv). Train streaming checkpoint from TF Hub.
3. **3 MoViNet classes**: studying, sleeping, other. "Distracted" is temporal logic. Phone is YOLO.
4. **Drop gaze entirely**: FaceLandmarker removed. Engagement formula reweighted: posture(0.30) + studying(0.40) + no_phone(0.30).
5. **YOLOv8n-pose over MediaPipe**: Same keypoints needed, shares framework with existing YOLO, lighter, faster.
6. **Single person assumption**: If YOLO detects >1 person, use largest bounding box. Multi-person is v0.4.
7. **Feature flag**: `USE_ML_DETECTOR` toggle keeps old system as fallback.
8. **MoViNet on full frame**: No person cropping for v0.3. May revisit if accuracy is poor.

## Risk Register

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|-----------|
| Python 3.11 + TF 2.17 + Metal fails | Low | CRITICAL | Phase 0 gate. Fallback: try 3.11 + TF 2.16 |
| K-700 YouTube links >40% dead | Medium | High | Target 1000 URLs/class. Supplement with OUC-CGE |
| MoViNet-A2-Stream fine-tuning OOMs on Apple Silicon | Medium | High | Reduce batch size to 2-4. Use gradient accumulation |
| val_accuracy < 75% | Medium | High | More data, try A0 (lighter) or A3 (heavier), add more augmentation |
| Domain gap: YouTube vs home cameras | HIGH | High | Qualitative webcam test after training. Contingency: record 200 in-domain clips |
| 3-model latency > 80ms (FPS < 12) | Medium | Medium | Run MoViNet every 5th frame (1 FPS for action, 30 FPS for phone/pose) |
| "Other/neutral" class too noisy | Medium | Medium | Monitor confusion matrix. Curate other samples if >15% → studying |
| CalibrationEngine port breaks scoring | Low | Medium | A/B test old vs new calibration on same video |
| MoViNet streaming state corruption | Low | Medium | reset_state() on camera disconnect, person absence >5s |

## Known Limitations (v0.3)

- **Single person only**: Multi-person handling deferred to v0.4
- **No gaze tracking**: Dropped with MediaPipe FaceLandmarker
- **Domain gap**: Model trained on YouTube/classroom footage, not home cameras
- **No in-domain eval set**: Using Kinetics validation only
- **FP32 inference only**: No quantization optimization
- **Full-frame MoViNet**: No person cropping (may classify background activity)
- **Night/IR mode**: Not tested — model trained on RGB only
