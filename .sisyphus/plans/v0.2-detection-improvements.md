# KID-WATCH v0.2 — Detection Improvements Plan

## Goal
Fix the accuracy issues found during live testing: too-lenient "studying" detection, head-pose-only gaze, camera-angle-dependent posture thresholds. Make the system work without manual calibration.

## Context
- v0.1 is working (992-line kid_watch.py, tested live on macOS)
- User found: head tilt down + eyes looking up = false "studying"
- Research complete: iris tracking, calibration strategies, posturr analysis, Dola competitive intel
- All improvements use existing MediaPipe stack (no new dependencies)

## Tasks

### Phase 1: Fix Gaze Detection (iris tracking)
- [ ] **Task 1.1**: Add iris landmark extraction to GazeDetector
  - Enable `refine_landmarks=True` in Face Landmarker (or equivalent in Tasks API)
  - Extract iris center landmarks: right iris 468-472, left iris 473-477
  - Compute iris vertical ratio per eye: `(iris_center.y - eye_top.y) / (eye_bottom.y - eye_top.y)`
  - Eye boundary landmarks: L_top=159, L_bottom=145, R_top=386, R_bottom=374
  - Files: `kid_watch.py` (GazeDetector class)
  - Parallelizable: No (foundation for Task 1.2)

- [ ] **Task 1.2**: Integrate iris ratio into "studying" decision logic
  - Current: `looking_at_desk = pitch > 15 AND abs(yaw) < 25`
  - New: `looking_at_desk = pitch > 15 AND abs(yaw) < 25 AND iris_vertical_ratio > 0.52`
  - Add iris ratio to dashboard display (debug info)
  - Add fallback: if face too small (inter-ocular < 30px), skip iris check
  - Files: `kid_watch.py` (GazeDetector class, DashboardRenderer)
  - Parallelizable: No (depends on 1.1)

### Phase 2: Improve Posture Detection (multi-signal + camera-invariant)
- [ ] **Task 2.1**: Replace forward-lean metric with joint angle calculations
  - Current: single forward-head angle (ear-shoulder dx/dy)
  - New: compute neck_angle (ear→shoulder→hip) and back_angle (shoulder→hip→knee)
  - Use landmarks: ear_mid(7,8), shoulder_mid(11,12), hip_mid(23,24), knee_mid(25,26)
  - Joint angles are camera-angle-invariant (work from ceiling, wall, or desk mount)
  - Files: `kid_watch.py` (PostureDetector class)
  - Parallelizable: Yes (independent of Phase 1)

- [ ] **Task 2.2**: Add forward-head detection via face size ratio
  - Steal from Posturr: track face width (eye corner distance) relative to baseline
  - If face width increases >10% from baseline → leaning toward screen
  - Use Face Landmarker eye corners: L_outer=33, L_inner=133, R_outer=263, R_inner=362
  - Files: `kid_watch.py` (PostureDetector class)
  - Parallelizable: No (depends on 2.1 for baseline infrastructure)

- [ ] **Task 2.3**: Formalize hysteresis for state transitions
  - Enter "slouching" threshold ≠ exit threshold (exit = 70% of enter)
  - Enter "studying" requires 0.7-1.0s sustained, exit requires 0.3-0.5s
  - Replace current 70%-of-30-frames with proper dwell-time hysteresis
  - Files: `kid_watch.py` (EngagementEngine class)
  - Parallelizable: Yes (independent of 2.1/2.2)

### Phase 3: Auto-Calibration (zero-touch)
- [ ] **Task 3.1**: Implement silent auto-calibration from first 15-25 seconds
  - On session start, collect "neutral" pose for 15-25s (clean frames only)
  - Clean frame = person detected + landmarks visibility > 0.6 + stable face size
  - Store median values as baseline: neck_angle, back_angle, iris_ratio, face_width
  - Use MAD (median absolute deviation) for robust threshold computation
  - Files: `kid_watch.py` (new CalibrationEngine class)
  - Parallelizable: No (depends on Phase 1 + 2 for metrics)

- [ ] **Task 3.2**: Add position-change detection and auto re-baseline
  - Detect when kid moves: YOLO bbox center shifts >25% OR face size changes >25% for >2s
  - Pause scoring, rebuild baseline over next 10-15s of clean frames
  - Store up to 3 baselines (desk A vs couch vs kitchen table)
  - Match to closest baseline on re-detection
  - Files: `kid_watch.py` (CalibrationEngine class)
  - Parallelizable: No (depends on 3.1)

### Phase 4: Dashboard & UX Polish
- [ ] **Task 4.1**: Update dashboard to show new metrics
  - Show: neck angle, back angle, iris ratio, calibration status
  - Show calibration progress bar during initial 15-25s
  - Show "recalibrating..." when position change detected
  - Color-code metrics: green (good) / yellow (warning) / red (bad)
  - Files: `kid_watch.py` (DashboardRenderer class)
  - Parallelizable: No (depends on all previous phases)
