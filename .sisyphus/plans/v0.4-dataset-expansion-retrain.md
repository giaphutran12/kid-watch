# KID-WATCH v0.4 — Dataset Expansion & MoViNet Retraining

## TL;DR

> **Quick Summary**: Download in-domain datasets (DAiSEE, DIPSER, IMPROVE), integrate with existing Kinetics-700 data, retrain MoViNet-A2-Stream classification head to improve study monitoring accuracy — especially for webcam-angle footage and "looking away" detection.
>
> **Deliverables**:
> - Integrated training dataset: Kinetics-700 + DAiSEE + DIPSER + IMPROVE
> - Retrained MoViNet-A2-Stream v0.4 with improved domain coverage
> - Label mapping for all 4 datasets to unified 3-class schema
> - Evaluation metrics: v0.4 vs v0.3 comparison, per-dataset performance
> - Rollback procedure: v0.3 model preserved as fallback
>
> **Estimated Effort**: Medium (2-4 weeks depending on download/compute time)
> **Parallel Execution**: YES — Phase 0 (license checks), Phase 1 (downloads), Phase 3 (preprocessing)
> **Critical Path**: Phase 0 (gate) → Phase 1 (download) → Phase 2 (analysis) → Phase 3 (preprocess) → Phase 4 (merge) → Phase 5 (retrain) → Phase 6 (evaluate) → Phase 7 (deploy)

---

## Context

### Original Request
Improve MoViNet-A2-Stream accuracy on in-domain data (home camera footage, webcam angles) by retraining with academic datasets that better represent real-world study scenarios.

### Interview Summary
**Key Discussions**:
- **Datasets**: DAiSEE (9,068 clips, engagement labels), DIPSER (multi-angle classroom), IMPROVE (multimodal, video-only extraction)
- **License verification**: CRITICAL gate before downloading. DAiSEE (academic use), DIPSER (CC BY 4.0), IMPROVE (verify), OUC-CGE (CC BY-NC-ND = EXCLUDED)
- **Label mapping**: Convert dataset-specific labels to unified studying/sleeping/other schema
- **Baseline preservation**: Keep v0.3 model + test set for regression testing
- **Retraining strategy**: Freeze backbone, retrain head only (same as v0.3)
- **Evaluation**: Cross-dataset testing to measure domain generalization

### Research Findings
- **DAiSEE**: 9,068 video clips from IITH, 4 affective states × 4 levels, 640×480, 30 FPS
- **DIPSER**: Multi-angle classroom footage, attention labels, various resolutions
- **IMPROVE**: Multimodal dataset with video, audio, text — extract video streams only
- **OUC-CGE**: CC BY-NC-ND (non-commercial) — EXCLUDED from training
- **Disk space**: ~300 GB needed for preprocessed data (raw + processed)

### Metis Review
**Critical Gaps Addressed**:
- License verification as Phase 0 gate (no training until verified)
- Disk space check before downloads (prevent mid-download failures)
- Label mapping validation (manual spot-check 20 clips per dataset)
- Regression testing (v0.3 test set preserved, must maintain ≥0.90 accuracy)
- Rollback procedure (v0.3 model untouched, config-based switching)

## Risk Register

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| DAiSEE download unavailable | Medium | High | Academic server may be down. Have DIPSER as backup. |
| DIPSER/IMPROVE requires registration | High | Medium | May need institutional affiliation. Plan for manual download. |
| Label mapping creates noisy data | Medium | High | Manual spot-check 20 clips per dataset. Iterate mapping. |
| Class imbalance after merging | High | Medium | Use class_weights + stratified sampling. |
| Disk space exhaustion (300+ GB) | Medium | High | Check space in Phase 0. Subsample if needed. |
| v0.4 accuracy < v0.3 | Low | Critical | Keep v0.3 test set for regression. Rollback if worse. |
| Feature extraction > 8 hours | Medium | Medium | Run overnight. Batch size=2 is memory-safe. |
| License violation for commercial use | Medium | Critical | Phase 0 gate. No training until licenses verified. |
| Domain gap remains (webcam vs academic) | Medium | Medium | Qualitative webcam test after deployment. Plan v0.5 with in-domain data. |
| v0.4 regression on v0.3 test set | Low | High | Regression gate: must maintain ≥0.90 accuracy on v0.3 test. |
